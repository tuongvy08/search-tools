# File Excel mẫu UAT local

Hai workbook dữ liệu tổng hợp, không phải danh mục pháp luật thật:

- `01-upsert-conflicts.xlsx`: chọn **Thêm / cập nhật**.
- `02-replace-scoped-conflicts.xlsx`: chọn **Thay đúng nhóm trường + tình trạng có trong file**.

Mỗi file có một sheet, đúng ba cột Code / Tình trạng quản lý / Ghi chú quản lý,
sáu dòng dữ liệu; không công thức, macro hoặc liên kết ngoài. Dùng nguyên
bản để đối chiếu checklist trong [UAT.md](../UAT.md); không dùng production.
