Nhập an toàn

Tạo snapshot mới

01

File rỗng, lỗi CAS, trùng định danh hoặc quantity không hợp lệ sẽ dừng trước apply. Trong lúc xử lý, snapshot active hiện tại vẫn đọc được.

Chỉ có chế độ thay toàn bộ. File đã xác nhận trở thành snapshot active mới; dòng vắng khỏi file sẽ không còn trong tồn hiện hành.

Quy tắc file

Kiểm tra nhanh

02
  • Đúng 8 cột theo file mẫu; CAS, giá và hạn dùng được để trống.
  • Quantity bắt buộc là số nguyên ≥ 0; 0 nghĩa là hết tồn.
  • Brand + Code + Size + Hạn dùng phải duy nhất, kể cả hạn trống.
  • Giá tồn là VND chưa VAT, chỉ hiển thị và không đi vào báo giá.
  • Ngày nhận dạng: ô ngày Excel, YYYY-MM-DD hoặc DD/MM/YYYY.
